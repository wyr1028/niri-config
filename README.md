# niri 設定檔

我的 [niri](https://github.com/YaLTeR/niri) 桌面環境設定，搭配 [DankMaterialShell (DMS)](https://danklinux.com)。

## 內容

| 檔案 | 說明 |
|---|---|
| `config.kdl` | 主設定（輸入、輸出、動畫、手勢、視窗規則、market 等） |
| `dms/` | DMS 產生的設定片段（色彩、版面、按鍵綁定、輸出…） |
| `dms/binds.kdl` | 快捷鍵綁定，提示皆為繁體中文 |
| `dms/colors.kdl` | 由 DMS 主題自動產生的顏色（blue 主題） |
| `local-bin/` | 自訂腳本副本：DMS wrapper + 速查表繁中翻譯 |
| `dotfiles/` | 本機其他可復現設定（shell、GTK、fcitx5、終端機、系統腳本…），含 `install.sh` |

## 環境

- **Compositor**：niri 26.04
- **Shell**：DankMaterialShell（DMS）＋ Quickshell
- **輸入法**：fcitx5 + Rime（依 session 自動切換主題）
- **主題**：DMS `blue`，focus-ring / border 為 `#42a5f5`
- **Gaps**：35px

## 快捷鍵提示

按 `Super + Shift + /`（即 `?`）會開啟 **DMS 主題化的快捷鍵彈窗**，所有提示均為繁體中文。

## 還原 / 部署

```sh
git clone https://github.com/wyr1028/niri-config.git ~/.config/niri
```

需先安裝 niri 與 DankMaterialShell；`dms/` 底下標註 `AUTO-GENERATED BY DMS` 的檔案會由 DMS 重新產生。
